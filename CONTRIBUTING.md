# Contribuindo para o MedControl

Obrigado por se interessar em contribuir! 

## Como contribuir
1. Faça um Fork do projeto.
2. Crie uma branch para sua funcionalidade (`git checkout -b feature/nova-funcionalidade`).
3. Commit suas mudanças (`git commit -m 'feat: Adiciona nova funcionalidade'`).
4. Dê um Push na branch (`git push origin feature/nova-funcionalidade`).
5. Abra um Pull Request.

## Requisitos
- O código deve passar em todos os testes (`pytest`).
- O código deve seguir o padrão de estilo (`flake8`).
